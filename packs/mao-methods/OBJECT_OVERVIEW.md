# Object Overview

- Profile: `methodology`
- Status: `confirmed`
- Subject: 毛泽东公开著作中的可迁移分析与工作方法

## 一句话主旨

从 7 个冻结来源版本提炼“毛泽东公开著作中的可迁移分析与工作方法”中的12 个候选能力骨架，并用独立反证、版本和权利边界约束迁移。

## 对象骨架

1. **feedback-integrity**：可用的反馈方法必须把一线证据、暂时判断、可逆试验和独立坏消息通道组成闭环。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#investigation-practice`、`https://www.12371.cn/special/mzdxj/d3j/#leadership-methods`、`https://www.12371.cn/special/mzdxj/d4j/#committee-methods`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`、`https://www.nber.org/papers/w16361`）
2. **investigation-before-judgment**：高影响判断必须先取得不同处境的一手事实，并预先写明什么证据会改变当前结论。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#investigation-practice`、`https://www.nber.org/papers/w16361`）
3. **practice-test-loop**：方法结论只能作为暂时假设，必须通过范围有限、结果可观察的实践再次检验和修正。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#investigation-practice`、`https://www.12371.cn/special/mzdxj/d3j/#leadership-methods`）
4. **anti-dogmatism-correction**：当抽象理论、上级转述或既有文本与现场事实冲突时，必须让可核验证据触发纠错而不是维护原结论。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#investigation-practice`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`、`https://www.nber.org/papers/w16361`）
5. **version-attribution**：历史文本的方法蒸馏必须区分最终公开版本、现场记录和现代推断，不能伪造人物立场。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#investigation-practice`、`https://www.dswxyjy.org.cn/n1/2021/0118/c219000-32003108.html`）
6. **contradiction-reclassification**：矛盾排序必须是可改判的阶段假设，并禁止把普通分歧转化为敌我身份。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#on-contradiction`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`）
7. **relational-problem-map**：复杂问题应先改写为目标、资源、事实、流程或权利关系，再比较候选解释，不能先把责任固定到个人身份。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#on-contradiction`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`）
8. **rights-bound-transfer**：历史方法的现代迁移必须以非暴力、守法、可逆、保留申辩和复核为硬边界。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/dyj/#on-contradiction`、`https://www.12371.cn/special/mzdxj/d3j/#leadership-methods`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`）
9. **protected-dissent-channel**：可用的组织反馈必须让异议和坏消息安全上行，并把收集、解释、执行和复核至少在角色上分开。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/d3j/#leadership-methods`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`、`https://www.nber.org/papers/w16361`）
10. **distribution-before-aggregate**：组织不能把高频声音、参与总量或总体指标直接当作代表性，必须检查沉默者、分布和承担成本的群体。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/d3j/#leadership-methods`、`https://www.nber.org/papers/w16361`）
11. **stage-experimentation**：弱势或高不确定条件下应先识别探索、验证、扩展或收缩阶段，再用窄目标和可逆试点积累证据与能力。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/d4j/#committee-methods`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`）
12. **center-work-coordination**：组织可以设置阶段性中心任务，但安全、合规、现金流、人员健康和必要协同必须作为不可被排序取消的并行底线。 （关系：capability-candidate；来源：`https://www.12371.cn/special/mzdxj/d4j/#committee-methods`、`https://www.gov.cn/test/2008-06/23/content_1024934_3.htm`）

## 内部张力

- 决议明确记录的失效：决议第20段指出，“文化大革命”对当时阶级形势和党政状况的估计“是完全错误的”，并具体记录了是非与敌我的混淆、知识分子和干部受到打击、党政组织受到冲击等后果。 关于以群众名义发动运动，决议写道： > “名义上是直接依靠群众，实际上既脱离了党的组织，又脱离了广大群众。” 第22段明确认为毛泽东对这场全局性、长时间的严重错误负有主要责任。第24段又把持续失效与…
- 对方法迁移的硬约束：这些材料表明，方法论文本中的“调查、群众、矛盾、纠错”不会自动约束实际权力。只要出现以下条件，就应停止套用历史框架： 1. 批评者会因提供坏消息遭受身份或职业惩罚。 2. 一个人或单一机构同时控制分类、决策、执行和复核。 3. 普通分歧被改写为敌我身份。 4. 大规模动员替代事实、法律程序和个体同意。 5. 试点没有退出、申诉、回滚和责任追究机制。
- 证据边界：该决议是中共中央的正式历史结论，既有高文本权威，也承担特定政治和组织功能。它能证明官方结论与制度反思，不能单独穷尽所有历史因果；具体事实仍需档案和独立研究交叉验证。
- 结构化主张：阶段性分类：Claim-Key: contradiction-reclassification Claim-Statement: 矛盾排序必须是可改判的阶段假设，并禁止把普通分歧转化为敌我身份。 Claim-Type: framework Evidence: 决议明确记录文化大革命中是非与敌我的混淆，以及错误分类给干部、知识分子和社会组织造成的严重后果。
