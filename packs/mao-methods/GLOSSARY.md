# Glossary

| 术语 | 对象内含义 | Evidence IDs |
|---|---|---|
| feedback-integrity | 可用的反馈方法必须把一线证据、暂时判断、可逆试验和独立坏消息通道组成闭环。 | `https://www.12371.cn/special/mzdxj/dyj/#investigation-practice` |
| investigation-before-judgment | 高影响判断必须先取得不同处境的一手事实，并预先写明什么证据会改变当前结论。 | `https://www.12371.cn/special/mzdxj/dyj/#investigation-practice` |
| practice-test-loop | 方法结论只能作为暂时假设，必须通过范围有限、结果可观察的实践再次检验和修正。 | `https://www.12371.cn/special/mzdxj/dyj/#investigation-practice` |
| anti-dogmatism-correction | 当抽象理论、上级转述或既有文本与现场事实冲突时，必须让可核验证据触发纠错而不是维护原结论。 | `https://www.12371.cn/special/mzdxj/dyj/#investigation-practice` |
| version-attribution | 历史文本的方法蒸馏必须区分最终公开版本、现场记录和现代推断，不能伪造人物立场。 | `https://www.12371.cn/special/mzdxj/dyj/#investigation-practice` |
| contradiction-reclassification | 矛盾排序必须是可改判的阶段假设，并禁止把普通分歧转化为敌我身份。 | `https://www.12371.cn/special/mzdxj/dyj/#on-contradiction` |
| relational-problem-map | 复杂问题应先改写为目标、资源、事实、流程或权利关系，再比较候选解释，不能先把责任固定到个人身份。 | `https://www.12371.cn/special/mzdxj/dyj/#on-contradiction` |
| rights-bound-transfer | 历史方法的现代迁移必须以非暴力、守法、可逆、保留申辩和复核为硬边界。 | `https://www.12371.cn/special/mzdxj/dyj/#on-contradiction` |
| protected-dissent-channel | 可用的组织反馈必须让异议和坏消息安全上行，并把收集、解释、执行和复核至少在角色上分开。 | `https://www.12371.cn/special/mzdxj/d3j/#leadership-methods` |
| distribution-before-aggregate | 组织不能把高频声音、参与总量或总体指标直接当作代表性，必须检查沉默者、分布和承担成本的群体。 | `https://www.12371.cn/special/mzdxj/d3j/#leadership-methods` |
| stage-experimentation | 弱势或高不确定条件下应先识别探索、验证、扩展或收缩阶段，再用窄目标和可逆试点积累证据与能力。 | `https://www.12371.cn/special/mzdxj/d4j/#committee-methods` |
| center-work-coordination | 组织可以设置阶段性中心任务，但安全、合规、现金流、人员健康和必要协同必须作为不可被排序取消的并行底线。 | `https://www.12371.cn/special/mzdxj/d4j/#committee-methods` |
