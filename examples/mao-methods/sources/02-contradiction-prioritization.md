# 矛盾特殊性与阶段性优先级

## 来源定位

- 一手文本入口：[《毛泽东选集》第一卷](https://www.12371.cn/special/mzdxj/dyj/)
- 核心篇目：《矛盾论》，1937年。
- 文本性质：短引、概念关系和现代使用边界。

## 可核验短引

《矛盾论》讨论复杂过程中的多重矛盾时写道：

> “其中必定有一种是主要的，起着领导的、决定的作用，其他则处于次要和服从的地位。”

同一篇文本反复强调具体分析矛盾的特殊性，不能把在一种场景有效的处理方式机械套到另一种场景。

## 可迁移机制

现代问题不应先给人贴“敌友”或阶级标签，而应把矛盾改写为可观察的关系：

1. 列出目标、资源、事实、流程和价值上的冲突。
2. 区分冲突性质：信息不足、目标不一致、资源约束、制度摩擦或权利冲突。
3. 提出两个以上可能的“主要矛盾”，为每个解释列证据和反证。
4. 选择当前最能牵动其他问题、又能通过可逆行动验证的一项。
5. 写明重新排序条件；主要矛盾是阶段假设，不是永久身份。

## 证据边界

“抓主要矛盾”容易制造过度压缩。复杂系统可能同时存在多个不可互相约减的目标，解决一个瓶颈也可能把风险转移给弱势群体。现代使用时必须保留备选解释、独立复核、申辩和改判机制。

本方法不能用于把同事、客户、社会群体或异议者敌人化，也不能把普通意见分歧升级为需要“斗争”的人格判断。

## 结构化主张：阶段性分类

Claim-Key: contradiction-reclassification
Claim-Statement: 矛盾排序必须是可改判的阶段假设，并禁止把普通分歧转化为敌我身份。
Claim-Type: framework
Evidence: 《矛盾论》要求具体分析矛盾的特殊性、主次和条件转化，因此“主要矛盾”不能成为脱离新证据的永久标签。

## 结构化主张：关系化问题地图

Claim-Key: relational-problem-map
Claim-Statement: 复杂问题应先改写为目标、资源、事实、流程或权利关系，再比较候选解释，不能先把责任固定到个人身份。
Claim-Type: framework
Evidence: 《矛盾论》要求具体分析不同矛盾的特殊性和相互条件，支持先描述关系和条件而不是先做人身归因。

## 结构化主张：现代迁移边界

Claim-Key: rights-bound-transfer
Claim-Statement: 历史方法的现代迁移必须以非暴力、守法、可逆、保留申辩和复核为硬边界。
Claim-Type: principle
Evidence: 普通组织中的意见分歧不能沿用战争和敌我分类，排序工具必须服从法律、安全与基本权利。
