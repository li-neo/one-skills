# 组织认知、试点与阶段推进

## 来源定位

- 一手文本入口：[《毛泽东选集》第四卷](https://www.12371.cn/special/mzdxj/d4j/)
- 核心篇目：《党委会的工作方法》，1949年；相关阶段方法来自持久战与集中力量的公开文本。
- 文本性质：工作方法转述，不复制军事操作。

## 可核验结构

《党委会的工作方法》把集体领导写成一组具体工作规则，包括书记善于当“班长”、把问题摆到桌面、互通情报、不懂就问、抓紧中心工作并兼顾其他工作。文中“弹钢琴”的比喻强调十个指头都要动作，但要有节奏和配合。

相关战略文本还区分长期阶段与具体行动：总体方向可以长期推进，但局部行动需要有限目标、准备和反馈。

## 可迁移机制

现代组织可使用以下非军事版本：

1. 先明确当前阶段：探索、验证、扩展或收缩。
2. 选择一个窄目标集中资源，同时写明不能牺牲的安全和权利约束。
3. 把目标拆成短周期、可逆试点，不用一次全面推广证明决心。
4. 会议中把事实、异议和未知项摆到桌面，指定独立核验者。
5. 让决策、执行和复核至少在角色上可区分。
6. 预先定义停止、回滚和阶段切换条件。

## 证据边界

战争中的集中、保密和命令逻辑不能直接迁移到普通公司、家庭、学校、社区或公共治理。现代组织中的参与者拥有法律、合同和基本权利，不是可被“歼灭”“孤立”或工具化的对象。

局部集中也不是永远只做一件事。安全、合规、现金流和人员健康等约束可能必须并行维护；“中心工作”不能成为忽视系统性风险的借口。

## 结构化主张：阶段化试点

Claim-Key: stage-experimentation
Claim-Statement: 弱势或高不确定条件下应先识别探索、验证、扩展或收缩阶段，再用窄目标和可逆试点积累证据与能力。
Claim-Type: framework
Evidence: 相关文本区分长期阶段和具体行动，局部行动需要有限目标、准备和反馈，不能用一次全面推广代替阶段检验。

## 结构化主张：中心任务与底线协调

Claim-Key: center-work-coordination
Claim-Statement: 组织可以设置阶段性中心任务，但安全、合规、现金流、人员健康和必要协同必须作为不可被排序取消的并行底线。
Claim-Type: framework
Evidence: 《党委会的工作方法》既要求抓紧中心工作，也用“弹钢琴”强调其他工作仍需有节奏地配合。

## 结构化主张：反馈完整性

Claim-Key: feedback-integrity
Claim-Statement: 可用的反馈方法必须把一线证据、暂时判断、可逆试验和独立坏消息通道组成闭环。
Claim-Type: framework
Evidence: 把问题摆到桌面、互通情报、不懂就问和角色区分共同要求决策能够接收新事实并在执行后复核。
