# 1981年历史决议中的失效边界

## 来源定位

- 官方文本：[《关于建国以来党的若干历史问题的决议》](https://www.gov.cn/test/2008-06/23/content_1024934_3.htm)
- 通过时间：1981年6月27日。
- 证据角色：反证与历史边界，不作为毛泽东本人自述。

## 决议明确记录的失效

决议第20段指出，“文化大革命”对当时阶级形势和党政状况的估计“是完全错误的”，并具体记录了是非与敌我的混淆、知识分子和干部受到打击、党政组织受到冲击等后果。

关于以群众名义发动运动，决议写道：

> “名义上是直接依靠群众，实际上既脱离了党的组织，又脱离了广大群众。”

第22段明确认为毛泽东对这场全局性、长时间的严重错误负有主要责任。第24段又把持续失效与个人专断、集体领导和民主集中制受损、法律和制度化不足联系起来。

## 对方法迁移的硬约束

这些材料表明，方法论文本中的“调查、群众、矛盾、纠错”不会自动约束实际权力。只要出现以下条件，就应停止套用历史框架：

1. 批评者会因提供坏消息遭受身份或职业惩罚。
2. 一个人或单一机构同时控制分类、决策、执行和复核。
3. 普通分歧被改写为敌我身份。
4. 大规模动员替代事实、法律程序和个体同意。
5. 试点没有退出、申诉、回滚和责任追究机制。

## 证据边界

该决议是中共中央的正式历史结论，既有高文本权威，也承担特定政治和组织功能。它能证明官方结论与制度反思，不能单独穷尽所有历史因果；具体事实仍需档案和独立研究交叉验证。

## 结构化主张：反馈完整性

Claim-Key: feedback-integrity
Claim-Statement: 可用的反馈方法必须把一线证据、暂时判断、可逆试验和独立坏消息通道组成闭环。
Claim-Type: framework
Evidence: 决议把个人专断、集体领导受损和民主法制制度化不足列入持续失效原因，表明理念上的调查不能替代独立反馈制度。

## 结构化主张：阶段性分类

Claim-Key: contradiction-reclassification
Claim-Statement: 矛盾排序必须是可改判的阶段假设，并禁止把普通分歧转化为敌我身份。
Claim-Type: framework
Evidence: 决议明确记录文化大革命中是非与敌我的混淆，以及错误分类给干部、知识分子和社会组织造成的严重后果。

## 结构化主张：现代迁移边界

Claim-Key: rights-bound-transfer
Claim-Statement: 历史方法的现代迁移必须以非暴力、守法、可逆、保留申辩和复核为硬边界。
Claim-Type: principle
Evidence: 决议指出问题应以符合宪法、法律和党章的措施解决，不能采用文化大革命的理论和方法。
